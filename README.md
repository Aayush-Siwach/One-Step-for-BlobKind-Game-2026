# One Step for Blobkind
Two friends stranded on a corrupted planet after crash landing, can they make it home before the sickness claims them?
Made by Aayush Siwach and Atharva Sathe
## How to Play
You can move two characters, Small Boy and Big Boy, where you can control both characters using the arrow keys and WASD, respectively. Your goal: reach the portal at the end of the sick planet to return home.
## Features
Different ways to make it home, can you find them all?
Simultaneous movement, use each other strengths to reach the end.
Unpredictable bouncing effect when landing, the sickeness has affected the very ground as well.
## Technologies
Used Godot game engine to create the game
## Assets
Most assets were made by Aayush Siwach except for the background, which was created from an online image through a pixelator software. Background music was found on imcomptech.com.
